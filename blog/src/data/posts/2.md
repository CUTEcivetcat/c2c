# C2C 二手交易平台部署记录

最近把一个 C2C 二手交易平台部署到了服务器，这里记录一下整体架构和踩过的坑。

## 架构

- **后端**：Spring Boot 2.7 单体应用，JDK 8
- **数据库**：MySQL 8
- **缓存**：Redis
- **Web**：Nginx
- **前端**：用户端 + 管理端两个 Vue 3 应用

## 部署要点

1. 后端打包后由 systemd 托管，监听本机 8080
2. Nginx 把 `/api/v1` 反代到后端，`/files/` 映射上传目录
3. 两个前端构建成静态文件，分别放 `/frontend` 和 `/admin-frontend`

## 踩坑记录

- **数据库表缺列**：实体和建表 SQL 不一致，查询直接报 `Unknown column`，对照实体逐表核对才找到
- **公网连数据库不稳定**：直连公网 MySQL/Redis 连接经常被断开，把连接池 `max-lifetime` 调短后稳定了

## 小结

做单体比微服务省心太多，不需要 Nacos、网关、消息队列，一台 4G 服务器就能跑起来。
