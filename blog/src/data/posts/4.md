# 前端性能优化的一点笔记

记录几个前端性能优化的小技巧，都是实践中能立竿见影的。

## 1. 图片懒加载

列表页的图片用 `loading="lazy"`，首屏只加载可视区域的图片：

```html
<img loading="lazy" src="..." alt="" />
```

## 2. 路由懒加载

Vue Router 里用动态 import，首屏只加载当前页面：

```js
{ path: '/article/:id', component: () => import('@/views/ArticleView.vue') }
```

## 3. 检查构建体积

构建后用 `vite build` 看产物大小，引入的库要按需引入，避免整包引入。

## 4. 缓存策略

静态资源带上 hash，设置长缓存；HTML 不缓存，保证更新即时生效。

优化前先测量，优化后要对比——没有数据支撑的优化都是玄学。
