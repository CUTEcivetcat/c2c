# 青禾集市 · 微信小程序（用户端）

> 状态：**v2.0 用户端完整版** —— 已完成全面重构，覆盖后端全部用户侧能力；原「残缺版」遗留问题均已修复。

青禾集市微信小程序端，配套单体后端 `com.c2c`（Spring Boot + MyBatis-Plus + Redis）。

## 三、本地运行

### 1. 后端
```bash
cd 后端目录
java -jar target/c2c-monolith.jar
# 需配置 wechat.mock=true（本机默认），mock 模式派生 openid，免真实 AppSecret
```

### 2. 数据库
`user` 表需含 `openid`、`login_source` 两列，变更见 `db-update.sql`（开发库已应用，生产前需执行）。

### 3. 微信开发者工具
1. 导入项目，选择本 `weapp/` 目录
2. 填 AppID（测试号即可）
3. 勾选「不校验合法域名」
4. 编译运行

> 服务器地址：`app.js → globalData.serverUrl`，正式版默认 `http://192.168.163.135:8080/api/v1`（测试服务器）；
> 本地联调改为 `http://127.0.0.1:8080/api/v1`。

## 四、本次重构修复的关键 Bug

| # | 问题 | 修复 |
|---|---|---|
| 1 | 订单支付/发货/收货/取消用 `POST`，后端为 `PUT` → **永远请求失败** | `api.js` 改为 `request.put` |
| 2 | 创建订单返回字段是 `orderId`，旧代码读 `id` → `/order/undefined/pay` | 改为取 `order.orderId` |
| 3 | 发布成色前端 0-3，后端枚举为 **1-4** → 成色全部错位 | `publish.js` 改为 `condition + 1` |
| 4 | 商品详情接口白名单不注入用户头 → `isFavorited` 恒为 false | 登录后单独调 `/favorite/check/{id}` 校正 |
| 5 | 我的发布状态映射错误（2 误标为已下架等） | 按后端枚举修正 {1在售,2已预订,3已售,4已下架,5违规下架} |
| 6 | 资料更新用 `POST /user/profile`，后端为 `PUT` 且参数走 query | 改为 `PUT ?nickname=&avatarUrl=&gender=&bio=` |
| 7 | 编辑**已下架商品**时详情接口 404，无法回填表单 | 从「我的发布」列表缓存商品数据回填 |
| 8 | 商品详情「收藏/评论」判断用 `isOwn()` 方法名与 data 字段冲突 | 数据化 `isOwn`，WXML 正确渲染操作栏 |
| 9 | 401 登录过期无统一处理 | `request.js` 清登录态并引导回「我的」 |
| 10 | 登录页 tab 用字符串比较、session 保存重复逻辑 | `Number()` 转换 + 统一走 `app.saveLogin` |

## 六、v2.2 用户实测反馈修复 + 账户能力增强（第三轮）

### 反馈问题修复

| 问题 | 根因 | 修复 |
|---|---|---|
| 修改个人信息点击没反应 | 「我的」页编辑资料 `data-url="/pages/user/edit"` 指向未注册路径（真实为 `/pages/user/edit/edit`），navigateTo 静默失败 | 修正跳转路径，`check-wxml.js` 新增 data-url 页面存在性校验 |
| 分类页面点击无反应 | `select` 函数把 bindtap 事件对象当 index 用，`categories[事件对象]` 为 undefined | 改为从 `e.currentTarget.dataset.index` 取值，并加分类未加载完成的防御 |
| 页面显示不完全 | ① `user/edit`、`user/home` 的 `require('../../utils/api.js')` 少一级目录，页面直接加载失败 ② 多个样式类缺失（`.msg-content/.brand/.text/.comment-list/.logs/.panel/.l-time` 等）③ 首页轮播空图渲染灰底空白 | 修正 require 路径；补齐全部缺失样式；banner 过滤无图项 + 图片加载失败自动隐藏 |

## 七、后端接口契约要点（前端已对齐）

- 鉴权：`Authorization: Bearer {token}`；白名单接口（商品详情、用户主页等）游客可访问
- 图片：后端返回 `/files/xxx` 相对路径，`request.js` 自动补全绝对地址
- 订单状态机：0 待支付 → 1 已支付 → 2 已发货 → 3 已收货 → 4 已完成；5 已取消（余额支付成功即自动完成）
- 商品状态：1 在售 / 2 已预订 / 3 已售 / 4 已下架 / 5 违规下架（上架用 `PUT /product/{id}/status` 头 `X-Status: 1`）
- 意向状态：1 待处理 / 2 已回复 / 3 已成交 / 4 已关闭
- 评价：`POST /rating {orderId, role(1买家/2卖家), ratedUserId, score, comment, tags}`；完成后用 `GET /rating/order/{id}` 判断是否已评
- 公告：`/latest` 首页横幅、`/publish` 发布页提示、`/force` 强制弹窗（`minSeconds` 最低停留）
