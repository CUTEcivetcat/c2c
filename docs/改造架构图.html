用户端前端（本次改 2 个页面） 本次新增 现有模块（只读复用） 数据层

① 用户端前端 Vue3（frontend / admin-frontend）

ProductPublishView.vue 改 新增「AI 智能填写」按钮：上传首图后一键回填 标题/分类/描述 + AI 建议价（¥Min~Max）提示条

DashboardView.vue 改 管理端新增「低碳循环看板」：累计减排/省钱/成交三卡 + 近30日减排趋势折线（ECharts）
▼ HTTP /api/v1（登录态）▼

② 后端 Spring Boot 2.7（新增 com.c2c.ai / com.c2c.eco）

ai 模块 新增 POST /ai/intelligent-publish（登录）
· 有 API Key → 多模态大模型（OpenAI 兼容 /chat/completions，提示词强制输出 JSON）
· 无 Key / 调用失败 → 本地规则引擎兜底（分类字典 + 历史成交均价 ±20%）
· 两路径共用「同分类已售商品均价」修正估价区间
eco 模块 新增 GET /eco/user/stats（我的环保贡献）
GET /admin/eco/overview（平台总览）
GET /admin/eco/trend?days=30（减排趋势）
统计口径：status=4 已完成订单；减排系数按一级分类字典（教材2.5 / 数码10 / 服饰6 / 其他5 kgCO₂e）
order / product 模块 不动 现有交易闭环、钱包担保、审核、IM 全部保留
eco 仅 LEFT JOIN 复用：order 表无 category_id / original_price，需 join product 取
⚠️ 鉴权要点：/admin/eco/** 走管理端鉴权，需在 AuthTokenFilter.permForPath() 加一行映射到 DASHBOARD 权限码；/ai/**、/eco/** 默认按普通用户登录鉴权，无需改白名单。

③ 数据层（不加新表）

MySQL 只读 product（status=3 已售均价 / category_id / original_price）
order（status=4 已完成 / complete_time 趋势分组）
Redis 新增用途 ai:publish:{md5(imageUrl)} 缓存 24h，重复发布免调用大模型
config/ 外部配置 新增 app.ai.base-url / api-key / model / timeout（占位符进 application.yml，真实 Key 走 config/ 不入仓）
实施顺序建议：ai 规则引擎路径（无 Key）→ eco 统计 → 前端发布页 → 个人中心 → 管理端看板 → 配真实 Key 联调 → 降级验证 → README/申报材料收尾。
