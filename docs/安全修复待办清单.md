## 四、服务器侧待办（非代码，需运维操作）

1. **配置 JWT 密钥（部署必做，否则拒绝启动）**：
   - 服务器生成随机密钥：`openssl rand -base64 32`（≥32 字节）
   - 通过环境变量注入后启动，例如：
     ```bash
     export JWT_SECRET="$(openssl rand -base64 32)"
     java -jar /softservice/c2c/app/app.jar
     ```
     或写入服务启动脚本/systemd 的 Environment 中。⚠️ 未设置 `JWT_SECRET` 时新版会**拒绝启动**（有意为之，防止弱密钥上线）。
   - 本地开发可用 `config/application-pro.yml` 的默认值 `c2c-local-dev-only-2026-secret-key-please-change`（仅本地，勿用于生产）。
2. **管理员与演示账号密码**：**按 owner 要求暂保留原密码**（种子 `<原种子密码>`，`sql/data.sql` 未改密码字段）。⚠️ 该密码已在登录页公示过、属公开值，**生产环境强烈建议尽快改随机密码**（管理端登录后修改，或改库 + 重新哈希）。
3. **清除 git 历史中的服务器 IP**：`git filter-repo` 重写历史（IP YOUR_SERVER_IP 已进公开仓库），强制推送后全员重新 clone。
4. **域名 + HTTPS**：为前后端配置域名与证书，小程序/前端不再直连 IP。
5. **服务器加固**：SSH 改端口 + 密钥登录；防火墙仅开 80/443/221；MySQL/Redis 强口令核验；上传目录 Nginx 禁脚本执行 + `nosniff`。
6. **数据库**：确认 `config/服务器密码.txt` 中的口令已改；生产库执行 `sql/tables/` 幂等迁移。
7. **Gitee 令牌轮换**：旧令牌 `YOUR_GITEE_TOKEN` 已在文档中标记泄露，务必删除重建（个人设置→私人令牌）。
