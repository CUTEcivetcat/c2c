# 青禾集市（C2C）项目计划书 · 总纲

> 版本：2026-11-02 · 维护人：Strawberry
> 定位：毕业设计「基于多模态大模型的二手交易平台智能发布与客服系统」的 master 计划
> 配套：本文是"做什么、何时做、谁来做"的总览；每项任务的具体做法看对应实施指南（见文末索引）

## 一、项目概述

- **产品**：校园 C2C 二手交易平台（青禾集市），前后端分离 + 微信小程序三端
- **技术栈**：Java 8 · Spring Boot 2.7 · MyBatis-Plus · MySQL/MariaDB · Redis · JWT / Vue3 + Vite + Element Plus / 原生小程序
- **AI 能力**：多模态智能发布（拍照估价+生成描述）、智能客服（规划）、管理端 AI 助手（G5 立项）；统一"可配置接入 + 规则引擎降级"架构
- **质量基线**：后端 43 单测 + 前端 3 组件测试，JDK8/17 双编译通过，CI（Gitee Go）已配置
