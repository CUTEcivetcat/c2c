### 3.5 后端加固批次（2026-11-17，清单 1–11）

> 范围：仅后端健壮性/一致性、性能并发与接口限流；支付为模拟实现，本轮不涉及支付改造。

#### P1 一致性 / 健壮性

| 编号 | 事项 | 落地口径 | 状态 |
|---|---|---|---|
| 1 | 商品详情缓存类型失真 | 详情缓存由 Redis Hash（字段 `toString()` 入 Hash、`BeanUtil` 回填）改为 ObjectMapper JSON 整对象序列化（key `product:info:<id>`，1h 过期）；解析失败/旧格式自动回源 DB；序列化失败不阻断主流程 | ✅ |
| 2 | 浏览量并发丢更新 | 浏览量改 SQL 层原子自增 `view_count = view_count + 1`（`setSql`），消除"读改写"非原子；内存对象 +1 仅用于本次展示；热门 ZSet `product:hot` 计分保留 | ✅（Redis 计数 + 定时落库仍为远期项，见 P-a） |
| 3 | 全局异常覆盖不全 | `GlobalExceptionHandler` 补齐：`MethodArgumentNotValidException`、`ConstraintViolationException`、`HttpMessageNotReadableException`（请求体缺失/非法 JSON）、`MissingServletRequestParameterException`、`MethodArgumentTypeMismatchException`、`NoHandlerFoundException`(404)；连同原有 `BindException` 与兜底 `Exception`(500) 统一返回 `R` 结构；`application.yml` 开启 `spring.mvc.throw-exception-if-no-handler-found` | ✅ |
| 4 | 分页参数无边界 | 新增 `common/utils/PageUtil`：页码 <1 回落 1，每页条数 <1 用默认 20、超 50 截断；商品/订单服务入口统一钳制；分页插件 `setMaxLimit(50)` + `setOverflow(true)`（越界回落首页） | ✅ |

**已知口径与边界（诚实记录）**
- 订单/支付 Redis 锁在 `@Transactional` 方法内、事务提交前释放，与既有领券锁模式一致；本轮未扩大为"事务提交后释放"。
- 限流为单机 Redis 窗口计数（固定窗口），未做滑动窗口/令牌桶；多实例共享同一 Redis 配额。
- 本轮未落地清单 12–17：`sms-echo-code` 默认值、token 存 localStorage、Controller 直注 Mapper 分层、全局 Jackson 日期/空值配置、IM 推送升级、全局 CORS（用户未要求）。
