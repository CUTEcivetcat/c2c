# K50 OlliteRT 本地大模型对接

> 来源：docs/OlliteRT-SpringAI对接文档（PDF 已整合，本文为权威 markdown 版）
> 用途：AI 功能（智能发布 / 智能客服 / 管理端助手）的**零成本局域网测试后端**
> 本项目适配：后端**不引入 Spring AI**（其依赖面向 Spring Boot 3.3，与本项目 SB 2.7 / JDK 8 不兼容），直接使用 `com.c2c.ai.client.AiOpenAiClient`（Hutool HTTP，OpenAI 兼容协议）对接；本文 §2~§5 的 Spring AI 写法保留作参考。

## 1. 服务信息

OlliteRT 运行在红米 K50 上，暴露 OpenAI 兼容 HTTP 接口：

| 项 | 值 |
|---|---|
| Base URL | `http://192.168.1.14:8000/v1` |
| 协议 | HTTP/1.1，SSE（流式） |
| 认证 | 无（未开启 Bearer Token） |

可用端点：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /v1/chat/completions | 对话补全（OpenAI 格式，支持流式） |
| POST | /v1/completions | 文本补全 |
| POST | /v1/messages | Anthropic Claude 格式 |
| GET | /v1/models | 列出已加载模型 |
| GET | /health | 健康检查 |

**前置条件**：

- K50 与后端服务同一局域网（Wi-Fi）；
- K50 上 OlliteRT 已启动并加载模型；App 设置 → 监听地址 = **局域网（所有接口）[0.0.0.0]**，不能是仅本机；
- 电池优化设为"不受限制"、最近任务锁定 OlliteRT，防止 MIUI 杀后台。

## 2. 本项目配置方式（AiOpenAiClient）

`config/application-pro.yml`（或环境变量）：

```yaml
app:
  ai:
    base-url: http://192.168.1.14:8000/v1   # OpenAI 兼容端点（注意带 /v1，与 Spring AI 不同）
    api-key: ollite-local                    # 无鉴权也必须非空，任意字符串
    model: gemma-3n-e2b                      # 用 GET /v1/models 查已加载模型名，区分大小写
    timeout: 60000                           # 手机推理首 token 2~10s，超时给足
```

- 已验证可调：`AiOpenAiClient.chatWithImage`（智能发布）、`AiOpenAiClient.chat`（智能客服，含 tools）。
- K50 **无 /embeddings 端点**：FAQ 检索 v1 用关键词评分；接云 API 后可升级向量检索。

## 3. Spring AI 写法参考（仅参考，本项目不使用）

依赖：`spring-ai-starter-model-openai:1.0.0` + Spring Boot 3.3.5  parent + spring-milestones 仓库。

```yaml
spring:
  ai:
    openai:
      base-url: http://192.168.1.14:8000    # 不带 /v1，Spring AI 自动拼接
      api-key: ollite-local
      chat:
        options:
          model: gemma-3n-e2b
          temperature: 0.7
          max-tokens: 1024
      embedding:
        enabled: false                       # 关闭默认连官方 embedding
```

```java
@Bean ChatClient chatClient(ChatClient.Builder builder) { return builder.build(); }
// 最简调用
chatClient.prompt().user(q).call().content();
// 流式
chatClient.prompt().user(q).stream().content();   // Flux<String>
// 多轮（推荐 ChatMemory）
chatClient.prompt().user(q)
    .advisors(new MessageChatMemoryAdvisor(chatMemory, "session-001", 20))
    .call().content();
```

## 4. 常见问题排查

| 现象 | 排查 |
|---|---|
| 连接超时 | 同一 Wi-Fi 关 VPN；监听地址必须 0.0.0.0；MIUI 允许 WLAN 联网；浏览器开 `http://192.168.1.14:8000/health` 能返 JSON 才算通 |
| 404 / model not found | 本项目 base-url **要带 /v1**；model 与 GET /v1/models 返回的 id 完全一致（区分大小写）；App 里先"启动服务器"加载模型 |
| 回答慢/首字久 | 手机端推理首 token 2~10s 正常；超时调大（本项目 app.ai.timeout）；选小模型（Gemma 3n E2B） |
| 流式变一次性 | Nginx 反代关 `proxy_buffering`；确认用 `.stream()` |
| 应用被杀连不上 | 省电策略"无限制"；最近任务加锁；开机自启动打开 |
